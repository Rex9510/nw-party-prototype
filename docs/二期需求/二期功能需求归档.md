## 一、归档背景与原则

### 1.1 归档背景

1期上线节奏紧、产品主线（学习、首页、三会一课、画像、审核）已基本能跑通，业务方同意将以下功能**整体后置到2期**：

- 小程序「服务」整个 Tab（党群共享服务 + 工作创业服务 + i龙岗拉起）
- 小程序「办公助手」九宫格全部子能力（除「党务智能问答」外）
- PC 管理端对应的「办公助手」与「服务配置」侧栏入口与功能
- 配套后台：模板维护、内容生成、模型对接等

**1期保留并保留入口**：党务智能问答（小程序首页单一跳转卡片）。

### 1.2 归档原则

| 原则 | 说明 |
|---|---|
| **整段归档** | 「服务 tab」不拆，保留整体作为 2期 一条线 |
| **保留入口不变** | 1期不在代码中删除服务 tab 屏幕组件（partyTools / lifeServices / career 等），仅去掉入口，便于 2期 还原 |
| **AI 问答不受影响** | 1期党务智能问答跳转卡片继续走 `navigateTo('aiQA')`；AIQAScreen 留作 1期 内嵌的 H5 跳转屏 |
| **PC 同步** | PC 端侧栏、工作台快捷入口、sub文案同步去掉/标注，避免演示时出现死链 |
