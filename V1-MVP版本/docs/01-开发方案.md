# 南湾党建 V1-MVP · 开发方案

> 编制时间：2026-07-25
> 范围：基于 `党组织需求V1-MVP版本.docx` + `202611南湾街道党校培训情况统计表.xlsx` 的真实 MVP 系统
> 与既有原型的关系：**独立产品**，不复用 `prototype/` 和 `pc-admin/`，但沿用同一业务域模型
> 状态：**待评审**，业务方确认后启动开发

---

## 一、范围与目标

### 1.1 业务目标

解决南湾街道党校集中学习培训的**录入 → 两级审核 → 学时归档 → 年度统计**全流程线上化，替代当前 Excel 手工流转。

### 1.2 范围圈定

**V1-MVP 包含**：
- 党员库管理（手动 + 批量导入）
- 培训活动录入（含 13+ 字段 + 照片必传 + 签到表附件）
- 两级审核流（社区初审 + 街道复审）
- 学时档案（个人汇总 + 明细）
- 年度统计与 Excel 导出

**V1-MVP 不包含**（V1.x/V2 再做）：
- 微信小程序原生版（H5 优先，uni-app 编译预留）
- 短信验证码登录
- 党务智能问答 / 智能审核
- 服务 tab / 办公助手九宫格
- PC 端（若有需求另起）

## 二、技术栈

| 层 | 选型 | 关键理由 |
|---|---|---|
| 前端 H5 | Vue 3 + Vite + TypeScript + Pinia + Vue Router + Vant | 移动端 H5 主流栈；TS 强类型；Vant 是字节/钉钉项目在用的移动端 UI 库 |
| 后期小程序 | uni-app（Vue 3 语法）编译到微信小程序 | **同源代码**，H5 → 小程序 0 重构 |
| 后端 | Python 3.11 + FastAPI + SQLAlchemy 2.0 + Pydantic v2 | 异步性能好；自动 OpenAPI；与既有 `server/` 风格延续 |
| 数据库 | PostgreSQL 16 | 字段多 + 后续 JSON 需求；强事务；阿里云 RDS PG 托管免运维 |
| 缓存 | Redis 7 | 登录态、限流、字典缓存 |
| 对象存储 | 阿里云 OSS（开发期可用 MinIO 本地替代） | 现场照片、签到表、导入模板 |
| 认证 | JWT (Access + Refresh) + bcrypt 密码哈希 | 不接短信，纯手机号+密码 |
| 导入导出 | 前端 SheetJS / 后端 openpyxl 异步生成 | 模板下载/批量导入/统计导出 |
| 部署 | 阿里云轻量 + Docker Compose + Nginx + GitHub Actions | 与既有 deploy 体系一致 |

### 3.2 关键业务规则

- **不可自审**：社区组织委员不能审核自己录入的活动（系统拦截，提示"请联系同社区其他委员或街道直审"）
- **学时手动填**：表单里"学时"字段由录入人填写，审核不修改
- **照片必传**：提交审核前必须上传至少 1 张现场照片，否则按钮置灰
- **签到表可选**：9 张内附件，可上传图片或 PDF
- **驳回留痕**：每次驳回带审核意见，存入 `audit_logs`
- **状态机**：草稿 → 待社区初审 → 待街道复审 → 已通过 / 已驳回 → 已驳回可重新编辑再提交

## 五、数据库设计（13 张核心表）

### 5.1 ER 概览

```
streets ─┬─ communities ─┬─ branches ─── members
         │               │                │
         │               │                │ (study_hours 按党员)
         │               │                │
         │               └─ users (角色: 街道/社区/支部/党员/系统管理员)
         │
         └─ activities (培训活动)
              ├─ activity_attachments (照片/签到表)
              ├─ activity_participants (活动-党员关联)
              └─ audit_flows / audit_logs (审核流)
                  │
                  └─ 通过后 → 写入 study_hours

lecturers / training_categories / training_sources (字典)
member_imports (批量导入记录)
```

### 5.2 表结构

```sql
-- 认证
users              id, phone, password_hash, role, street_id, community_id, branch_id, name, status, created_at
refresh_tokens     id, user_id, token_hash, expires_at, revoked

-- 组织架构
streets            id, name
communities        id, street_id, name
branches           id, community_id, name

-- 党员
members            id, branch_id, name, phone, id_card_no, gender, join_date, status, created_by, created_at
member_imports     id, file_url, total_rows, success_rows, failed_rows, error_log, created_by, created_at

-- 培训活动（13+ 字段，对齐 xlsx）
activities         id, organizer_branch_id, training_at, location, lecturer_id, theme,
                   participant_count, online_offline, is_centralized, is_innovation_theory,
                   source_type, audience_category, study_hours, status, created_by, created_at
activity_attachments id, activity_id, kind (photo/signin), file_url, sort
activity_participants id, activity_id, member_id, study_hours, attendance_status

-- 审核
audit_flows        id, activity_id, current_node, status, created_at
audit_logs         id, activity_id, node, operator_id, action (submit/approve/reject), comment, created_at

-- 档案
study_hours        id, member_id, year, total_hours, activity_count, updated_at

-- 字典
lecturers          id, name, intro
training_categories id, code, name (社区党员/机关党员/两新党组织党员)
training_sources   id, code, name (上级送课/自行组织)
```

**完整 DDL 见** `02-数据库设计.md`（另行编写）。

## 六、API 设计（约 35 个 endpoint）

### 6.1 认证

```
POST   /api/auth/login              手机号+密码登录，返回 access+refresh
POST   /api/auth/refresh            刷新 access
GET    /api/auth/me                 当前用户信息
POST   /api/auth/logout             注销
```

### 6.2 组织架构 + 党员

```
GET    /api/orgs/tree                街道→社区→支部树
GET    /api/branches                 支部列表（按 community_id 过滤）
GET    /api/members                  党员列表（分页+按支部/社区过滤）
GET    /api/members/{id}             党员详情
POST   /api/members                  新增
PATCH  /api/members/{id}             修改
DELETE /api/members/{id}             删除
POST   /api/members/import           批量导入（multipart xlsx）
GET    /api/members/template         下载导入模板
```

### 6.3 培训活动

```
GET    /api/activities               列表（分页+状态/社区/时间过滤）
POST   /api/activities               录入
GET    /api/activities/{id}          详情
PATCH  /api/activities/{id}          修改（仅草稿/已驳回）
POST   /api/activities/{id}/submit   提交审核
POST   /api/activities/{id}/attachments   上传附件
DELETE /api/activities/{id}/attachments/{aid}  删附件
```

### 6.4 审核

```
GET    /api/audit/pending            待办（按当前用户角色自动过滤）
GET    /api/audit/history            历史
POST   /api/audit/{activityId}/approve   通过
POST   /api/audit/{activityId}/reject    驳回（带 comment）
```

### 6.5 学时 + 统计

```
GET    /api/study-hours              个人档案（按年度）
GET    /api/study-hours/{memberId}   个人明细
GET    /api/stats/yearly             年度统计（按类别）
GET    /api/stats/export             导出 xlsx
```

### 6.6 字典

```
GET    /api/dict/lecturers
POST   /api/dict/lecturers
PATCH  /api/dict/lecturers/{id}
GET    /api/dict/training-categories
GET    /api/dict/training-sources
```

**完整 OpenAPI 由 FastAPI 自动生成，开发完成后挂到 `/docs`**。

## 九、验收标准

### 9.1 功能验收（每个 sprint 结束必须通过）

- [ ] H5 在 Chrome/Edge/Safari 移动模拟器下无样式错误
- [ ] 后端所有 endpoint 通过 Postman/curl 自动化测试
- [ ] 不可自审规则单元测试覆盖
- [ ] 批量导入错误行有明确提示（行号+错误原因）
- [ ] 导出 xlsx 结构与现有 `202611南湾街道党校培训情况统计表.xlsx` 完全对齐
- [ ] 角色权限隔离手动验证（街道账号看不到其他街道数据）

### 9.2 性能验收

- 列表分页查询 < 500ms（1000 行数据）
- 附件上传 < 3s（单张 5MB 以内）
- 批量导入 100 行 < 5s

### 9.3 安全验收

- 密码 bcrypt 哈希存储
- JWT access 2h 过期，refresh 7d
- 附件上传校验 MIME + 大小
- SQL 注入/ XSS 防护（ORM + 前端转义）
