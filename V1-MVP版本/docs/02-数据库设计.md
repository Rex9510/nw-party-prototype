# V1-MVP · 数据库设计

> 配套文档：`01-开发方案.md`
> 数据库：PostgreSQL 16
> ORM：SQLAlchemy 2.0（Python）

---

## 一、设计原则

1. **所有表带 `created_at` / `updated_at`**（审计用）
2. **软删除优先**：用 `status` 字段或 `deleted_at`，不直接 DELETE
3. **多租户隔离**：所有业务表带 `community_id`（街道级查询不带此条件）
4. **金额/计数用整型**：人数、学时等用 `int` 不用 `float`
5. **字典值用 `varchar` 存 code**，不直接存中文 label（便于国际化）
6. **所有外键有索引**（SQLAlchemy `index=True`）

## 二、完整 DDL

### 2.1 认证模块

```sql
-- 用户
CREATE TABLE users (
  id              BIGSERIAL PRIMARY KEY,
  phone           VARCHAR(20) NOT NULL UNIQUE,
  password_hash   VARCHAR(255) NOT NULL,
  name            VARCHAR(64) NOT NULL,
  role            VARCHAR(32) NOT NULL,  -- street_lead / community_organizer / branch_secretary / member / system_admin
  street_id       BIGINT,
  community_id    BIGINT,
  branch_id       BIGINT,
  status          VARCHAR(16) NOT NULL DEFAULT 'active',  -- active / disabled
  last_login_at   TIMESTAMPTZ,
  created_at      TIMESTAMPTZ NOT NULL DEFAULT now(),
  updated_at      TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE INDEX idx_users_role ON users(role);
CREATE INDEX idx_users_community ON users(community_id);
CREATE INDEX idx_users_branch ON users(branch_id);

-- 刷新 token
CREATE TABLE refresh_tokens (
  id              BIGSERIAL PRIMARY KEY,
  user_id         BIGINT NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  token_hash      VARCHAR(255) NOT NULL UNIQUE,
  expires_at      TIMESTAMPTZ NOT NULL,
  revoked         BOOLEAN NOT NULL DEFAULT false,
  created_at      TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE INDEX idx_refresh_user ON refresh_tokens(user_id);
```

### 2.2 组织架构

```sql
CREATE TABLE streets (
  id          BIGSERIAL PRIMARY KEY,
  name        VARCHAR(64) NOT NULL,
  created_at  TIMESTAMPTZ NOT NULL DEFAULT now()
);

CREATE TABLE communities (
  id          BIGSERIAL PRIMARY KEY,
  street_id   BIGINT NOT NULL REFERENCES streets(id),
  name        VARCHAR(64) NOT NULL,
  created_at  TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE INDEX idx_communities_street ON communities(street_id);

CREATE TABLE branches (
  id            BIGSERIAL PRIMARY KEY,
  community_id  BIGINT NOT NULL REFERENCES communities(id),
  name          VARCHAR(128) NOT NULL,
  created_at    TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE INDEX idx_branches_community ON branches(community_id);
```

### 2.3 党员

```sql
CREATE TABLE members (
  id              BIGSERIAL PRIMARY KEY,
  branch_id       BIGINT NOT NULL REFERENCES branches(id),
  name            VARCHAR(64) NOT NULL,
  phone           VARCHAR(20) NOT NULL,
  id_card_no      VARCHAR(32),
  gender          VARCHAR(8),  -- male / female / other
  join_date       DATE,
  status          VARCHAR(16) NOT NULL DEFAULT 'active',  -- active / transferred / dimission
  created_by      BIGINT REFERENCES users(id),
  created_at      TIMESTAMPTZ NOT NULL DEFAULT now(),
  updated_at      TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE UNIQUE INDEX idx_members_phone ON members(phone) WHERE status = 'active';
CREATE INDEX idx_members_branch ON members(branch_id);
CREATE INDEX idx_members_name ON members(name);

-- 批量导入记录
CREATE TABLE member_imports (
  id              BIGSERIAL PRIMARY KEY,
  file_url        VARCHAR(512) NOT NULL,
  total_rows      INT NOT NULL,
  success_rows    INT NOT NULL DEFAULT 0,
  failed_rows     INT NOT NULL DEFAULT 0,
  error_log       JSONB,  -- [{row: 5, error: "手机号重复"}, ...]
  created_by      BIGINT REFERENCES users(id),
  created_at      TIMESTAMPTZ NOT NULL DEFAULT now()
);
```

### 2.4 培训活动

```sql
CREATE TABLE activities (
  id                    BIGSERIAL PRIMARY KEY,
  organizer_branch_id   BIGINT NOT NULL REFERENCES branches(id),
  community_id          BIGINT NOT NULL REFERENCES communities(id),  -- 冗余字段，便于按社区过滤
  training_at           TIMESTAMPTZ NOT NULL,
  location              VARCHAR(255) NOT NULL,
  lecturer_id           BIGINT REFERENCES lecturers(id),
  theme                 VARCHAR(255) NOT NULL,
  participant_count     INT NOT NULL DEFAULT 0,
  online_offline        VARCHAR(16) NOT NULL,  -- online / offline / hybrid
  is_centralized        BOOLEAN NOT NULL,  -- 是否集中学习
  is_innovation_theory  BOOLEAN NOT NULL,  -- 是否党的创新理论教育
  source_type           VARCHAR(16) NOT NULL,  -- upper_send / self_organize
  audience_category     VARCHAR(16) NOT NULL,  -- community_member / govt_member / ngo_member
  study_hours           NUMERIC(5,1) NOT NULL,  -- 单次活动总学时，可分摊到个人
  status                VARCHAR(16) NOT NULL DEFAULT 'draft',  -- draft / pending_community / pending_street / approved / rejected
  reject_reason         TEXT,  -- 驳回原因
  created_by            BIGINT NOT NULL REFERENCES users(id),
  created_at            TIMESTAMPTZ NOT NULL DEFAULT now(),
  updated_at            TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE INDEX idx_activities_status ON activities(status);
CREATE INDEX idx_activities_community ON activities(community_id);
CREATE INDEX idx_activities_organizer ON activities(organizer_branch_id);
CREATE INDEX idx_activities_training_at ON activities(training_at);

-- 活动附件
CREATE TABLE activity_attachments (
  id            BIGSERIAL PRIMARY KEY,
  activity_id   BIGINT NOT NULL REFERENCES activities(id) ON DELETE CASCADE,
  kind          VARCHAR(16) NOT NULL,  -- photo / signin
  file_url      VARCHAR(512) NOT NULL,
  file_size     INT,
  sort          INT NOT NULL DEFAULT 0,
  uploaded_by   BIGINT REFERENCES users(id),
  created_at    TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE INDEX idx_attach_activity ON activity_attachments(activity_id);

-- 活动-参加人员
CREATE TABLE activity_participants (
  id                  BIGSERIAL PRIMARY KEY,
  activity_id         BIGINT NOT NULL REFERENCES activities(id) ON DELETE CASCADE,
  member_id           BIGINT NOT NULL REFERENCES members(id),
  study_hours         NUMERIC(5,1) NOT NULL,  -- 该党员本次活动获得学时
  attendance_status   VARCHAR(16) NOT NULL DEFAULT 'signed',  -- signed / absent / late
  created_at          TIMESTAMPTZ NOT NULL DEFAULT now(),
  UNIQUE(activity_id, member_id)
);
CREATE INDEX idx_ap_activity ON activity_participants(activity_id);
CREATE INDEX idx_ap_member ON activity_participants(member_id);
```

### 2.5 审核流

```sql
CREATE TABLE audit_flows (
  id            BIGSERIAL PRIMARY KEY,
  activity_id   BIGINT NOT NULL UNIQUE REFERENCES activities(id) ON DELETE CASCADE,
  current_node  VARCHAR(32) NOT NULL,  -- community_review / street_review / done
  status        VARCHAR(16) NOT NULL,  -- in_progress / approved / rejected
  created_at    TIMESTAMPTZ NOT NULL DEFAULT now(),
  updated_at    TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE INDEX idx_af_activity ON audit_flows(activity_id);

CREATE TABLE audit_logs (
  id            BIGSERIAL PRIMARY KEY,
  activity_id   BIGINT NOT NULL REFERENCES activities(id) ON DELETE CASCADE,
  node          VARCHAR(32) NOT NULL,  -- community_review / street_review
  operator_id   BIGINT NOT NULL REFERENCES users(id),
  action        VARCHAR(16) NOT NULL,  -- submit / approve / reject
  comment       TEXT,
  created_at    TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE INDEX idx_audit_activity ON audit_logs(activity_id);
CREATE INDEX idx_audit_operator ON audit_logs(operator_id);
```

### 2.6 学时档案

```sql
CREATE TABLE study_hours (
  id              BIGSERIAL PRIMARY KEY,
  member_id       BIGINT NOT NULL REFERENCES members(id),
  year            INT NOT NULL,
  total_hours     NUMERIC(7,1) NOT NULL DEFAULT 0,
  activity_count  INT NOT NULL DEFAULT 0,
  updated_at      TIMESTAMPTZ NOT NULL DEFAULT now(),
  UNIQUE(member_id, year)
);
CREATE INDEX idx_study_member ON study_hours(member_id);
CREATE INDEX idx_study_year ON study_hours(year);
```

> **写入学时档案时机**：`activities.status` 变为 `approved` 时，事务内对每个 `activity_participants` 累加到对应 `(member_id, year)` 的 `study_hours`。可加 trigger 或在 service 层处理。

## 三、关键索引汇总

| 字段 | 索引类型 | 原因 |
|---|---|---|
| `members.phone` | UNIQUE partial | 党员查重 |
| `members.branch_id` | BTREE | 按支部过滤 |
| `activities.status` | BTREE | 待办列表 |
| `activities.community_id` | BTREE | 社区隔离 |
| `activities.training_at` | BTREE | 时间范围查询 |
| `activity_participants(member_id, activity_id)` | UNIQUE | 防止重复参加 |
| `study_hours(member_id, year)` | UNIQUE | 累加写入 |
| `audit_flows.activity_id` | UNIQUE | 一活动一流 |

## 四、数据量预估（按南湾街道 4000 党员算）

| 表 | 年增 | 总规模（5年） |
|---|---|---|
| `members` | -100/+500 | 4500 |
| `activities` | ~300 | 1500 |
| `activity_participants` | ~300 × 20 = 6000 | 30000 |
| `audit_logs` | ~900 | 4500 |
| `study_hours` | 4000 | 4000（年度更新） |
| `activity_attachments` | ~3000 张照片 | 15000 |

5 年总规模 < 10 万行，**单表不需分区**。PG 单机足够。

## 五、迁移与版本管理

- 使用 **Alembic** 管理 schema migration
- 迁移文件命名：`alembic/versions/xxxx_add_xxx.py`
- 每次建表/改字段必须生成 migration 脚本
- 生产部署通过 `alembic upgrade head` 自动执行
