# V1-MVP · 党员批量导入模板设计

> 配套文档：`01-开发方案.md` / `02-数据库设计.md`
> 业务场景：街道级一次性导入存量党员；社区级小批量补录

## 一、模板文件结构

**文件格式**：`.xlsx`（兼容 Excel 2007+ / WPS / 钉钉表格）
**Sheet 名**：`党员信息`
**首行**：表头
**数据行**：从第 2 行开始

### 1.1 表头（11 列）

| 列 | 字段 | 必填 | 格式 | 示例 | 校验 |
|---|---|---|---|---|---|
| A | 支部名称 | ✅ | 文本 | 南湾社区第一党支部 | 必须存在于 `branches` 表，否则该行报错 |
| B | 姓名 | ✅ | 文本 | 张伟 | 非空，长度 ≤ 64 |
| C | 手机号 | ✅ | 文本 | 13812345678 | 11位数字，全局唯一（按 R08 决策） |
| D | 身份证号 | ❌ | 文本 | 440307199001011234 | 18位，含校验位 |
| E | 性别 | ❌ | 枚举 | 男 / 女 / 其他 | 仅这三个值 |
| F | 入党时间 | ❌ | 日期 | 2019-03-15 | YYYY-MM-DD |
| G | 状态 | ❌ | 枚举 | 在职 / 转入 / 转出 / 预备 | 默认"在职" |

## 二、校验规则

### 2.1 行级校验（导入时按行处理）

| 错误码 | 触发条件 | 处理 |
|---|---|---|
| E001 | 支部名称不存在 | 该行标记失败，提示"支部XXX不存在" |
| E002 | 姓名为空 | 该行标记失败 |
| E003 | 手机号格式错误（非11位数字） | 该行标记失败 |
| E004 | 手机号已存在（active 状态） | 该行标记失败，提示"与现有党员XXX重复" |
| E005 | 身份证号格式错误 | 该行标记失败 |
| E006 | 性别不在枚举中 | 该行标记失败 |
| E007 | 入党时间格式错误 | 该行标记失败 |

### 2.2 文件级校验

- **文件大小**：≤ 5MB
- **总行数**：≤ 1000 行（超出截断 + 提示）
- **表头校验**：必须严格匹配 7 列（顺序、名称），否则整文件拒绝

### 2.3 事务策略

- **全有全无模式（推荐）**：任何一行失败，整个文件回滚，提示用户修正后重传
- **部分成功模式**（备选）：成功的行入库，失败行下载错误报告（`error_log` 存 JSONB）

> **建议默认全有全无**，简化用户操作。V1.x 再加部分成功模式。

## 四、模板下载

```
GET /api/members/template

返回：流式 xlsx 文件
文件名：党员导入模板.xlsx
Content-Type: application/vnd.openxmlformats-officedocument.spreadsheetml.sheet
```

模板特点：
- 第 1 行：表头（带样式：加粗 + 底色）
- 第 2 行：示例数据（带注释"请删除本行后填入真实数据"）
- 列宽自适应
- 性别/状态列加数据验证下拉框（避免手输错误）

---

## 五、并发与重复导入

- **同一文件重复上传**：生成新的 `member_imports` 记录，但**不重复入库**（靠 phone 唯一约束拦截）
- **并发导入**：依赖 DB 唯一约束，不需额外锁
- **导入进度**：V1 不做异步/进度条（同步处理，< 1000 行 < 5 秒），V1.x 改异步

## 六、待业务方确认

1. **R08 手机号唯一**：是否全局唯一？
2. **批量上限**：1000 行/次够不够？（南湾 4000 党员一次性导入可能需要 4 次，建议调到 2000）
3. **失败模式**：默认全有全无，部分成功模式要不要做？
4. **示例数据**：模板里要不要带 1-2 行示例？还是空模板？
